# LabWebsite v1.7: notes (2026-10-15)

v1.7 is v1.6 (`versions/labwebsite-v1.6/`, unchanged) with a polish pass: no new content, sections, colours or decorative elements, the same five views, routes and ids (diffed: every `id=` and every in-page `href="#…"` is identical to v1.6). Build, check and shot procedure as v1.6 / v1.4. Almost all CSS lives in one appended block at the end of `<style>` ("v1.7 polish"), numbered like the list below; markup changes are listed per item.

Measurement method: besides `tools/shot.py`, a settled probe (scratchpad, not kept) loaded each route, scrolled through, **waited 2.6 s for the reveals to finish**, then measured with `getBoundingClientRect`. This matters: shot.py captures ~0.3 s after scrolling back to the top, so the full-page tiles catch the staggered reveals mid-way (cards 18 px low, Q numerals mid-tint). Several defects in the v1.6 tiles were that, not layout; each item says which.
